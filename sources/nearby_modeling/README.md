# Nearby modeling datasets and published model results

Retrieved and audited October 13, 2026. These are source files, not new experimental data or local model predictions. Run `python code/experiments/audit_nearby_datasets.py` from the repository root to reproduce counts and extract the relevant benchmark rows. Checksums are in `file_checksums.json`; extracted measurements and published correlations are in `audit.json`.

## Sources

- `bedbrook2019_data1.csv` through `bedbrook2019_data4.csv`: Supplementary Data 1–4 from [Bedbrook et al., Nature Methods 2019](https://www.nature.com/articles/s41592-019-0583-8). Downloads: `https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41592-019-0583-8/MediaObjects/41592_2019_583_MOESM4_ESM.csv` through `MOESM7_ESM.csv`. Data 1 contains literature sequences/current values; Data 2 measured engineered sequences and properties; Data 3 **model-predicted designs, not measured labels**; Data 4 feature weights, not variants. Preserve publisher attribution/terms; access is not a blanket commercial-use license. Original code is [fhalab/channels](https://github.com/fhalab/channels), inspected at revision `da2f6651a760be6b8daec06467272b0ac2d8aeeb`. Pickled repository objects were not executed.
- `rhomax_by_wild_type.csv.gz`: [FLIP2 public rhodopsin split](https://flip.protein.properties/assets/splits/rhomax/by_wild_type.csv.gz), [dataset description and attribution](https://flip.protein.properties/). CC-BY 4.0 attribution to FLIP2 and original Karasuyama/Inoue/Sela studies. This is an absorption-wavelength dataset, not transport data. File includes 884 records and 878 distinct sequences. Validation records have `set=train` and `validation=True`; actual fitting set excludes those records.
- `kir2_function_mod.csv`, `kir2_surface_mod.csv`: original [KirDMS](https://github.com/schmidt-lab/KirDMS) source tables at revision `76cab17b04e2041b3818bcadfc225cd58c9f231f`, from `Manuscript_SourceData/input_data/function_mod.csv` and `surface_mod.csv`. [Primary paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC9273215/). Original construct includes an inserted extracellular tag; audit numbering/control handling before joining to an untagged reference. Raw-table row counts differ from ProteinGym's processed assay counts.
- `proteingym_reference.csv`: [ProteinGym reference metadata](https://github.com/OATML-Markslab/ProteinGym/blob/144fe22b07dfaeec2b366f2346203a9838a55b4c/reference_files/DMS_substitutions.csv).
- `proteingym_zero_shot_spearman.csv`: [published per-assay zero-shot results](https://github.com/OATML-Markslab/ProteinGym/blob/144fe22b07dfaeec2b366f2346203a9838a55b4c/benchmarks/DMS_zero_shot/substitutions/Spearman/DMS_substitutions_Spearman_DMS_level.csv).
- `proteingym_supervised_contiguous_spearman.csv`: [published five-fold contiguous-position supervised results](https://github.com/OATML-Markslab/ProteinGym/blob/144fe22b07dfaeec2b366f2346203a9838a55b4c/benchmarks/DMS_supervised/substitutions/Spearman/DMS_substitutions_Spearman_DMS_level_fold_contiguous_5.csv).

All ProteinGym files are pinned to `144fe22b07dfaeec2b366f2346203a9838a55b4c`. Metadata/results were downloaded; the full ProteinGym sequence datasets and precomputed per-variant model scores were not downloaded. Reported correlations are **not reproduced local runs** and may use model releases/scoring details different from our previous local benchmarks. Supervised and zero-shot protocols are distinct. Do not use benchmark headline correlation as evidence of improved-over-WT hit enrichment.
