{\LARGE\bfseries\color{ink} GtACR2: choose the experiment by the claim}\hfill October 12, 2026

\textbf{Conclusion:} GtACR2 is scientifically feasible, but not yet a low-setup project for a lab-automation startup. Use existing bacterial transport capability if available; otherwise defer wet-lab work or outsource functional validation. Do not build a patch-clamp capability for this pilot.

\textbf{Recommended objective:} faster current shutoff while retaining useful low-light current. Freeze the tradeoff and analysis before choosing variants. Greater expression, current and intrinsic conductance are different claims.

\textbf{Partner-fit gate:} start at 0. Go to 1 only if existing bacterial apparatus supports the transport assay; proceed to 2 only if controls pass. Use 3--5 through an established external electrophysiology facility. Without either route, defer GtACR2 experiments. A new fluorescent plate assay is development work, not a shortcut.

\textbf{Budget assumptions:} USD estimates, not quotes. Each row is a standalone scope, not an add-on price. Materials-only assumes staff/equipment in kind. Paid projects assume \$75/h preparation/analysis, \$150/h electrophysiology and 25\% contingency; do not double-count a recording technician. Level 0 research effort is in kind. Existing trained workflows required; no new rig/lab, procurement delays or computing-task validation included. Missing bacterial measurement/lighting: separately quote a provisional \$1--4k equipment allowance plus commissioning.

\textbf{Decision gates:} reproduce controls $\rightarrow$ confirm direct function $\rightarrow$ repeat hits independently $\rightarrow$ test neuronal inhibition against stGtACR2. Pilot cell counts are planning targets, not power guarantees. Voltages, light dose, abundance and preparation-day variation must be controlled.

\textbf{Ask the partner:} Which apparatus already exists? Who supplies verified constructs? What cash/in-kind ceiling fits? Request a capped pilot quote with usable recordings, optical calibration, raw data and repeat/stop rules. Academic-only catalog access is not assumed for a company.
